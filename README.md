# Scrapebox, but without the scraping

I've used Scrapebox for a long time for the line tools (not only with URLs), but haven't used the actual scraping/submission functions in years. The other day, Scrapebox servers were down and I decided to create a version that has nothing but the line tools.

The UI is similar to Scrapebox, so you'll find that you probably knows where things are already.

Some new features you will also notice:
 - The ability to manipulate the lines in the textarea.
 - Remove URLs containing and not containing opens a teaxtarea where multiple words/phrases/etc can be used (opposed to being forced to only use one or a file).
 - "Show Duplicates" has been added, so not only can you remove duplicates, but you can now show the duplicate items as well.
 - Spin URLs, ability to automatically spin URLs into {this|URL} format.

## How to Use

Download the latest release and open ScrapeboxUrlUtility.exe.

## Other Notes

Copying and pasting tabbed content, i.e. from Excel, is supported, but you must press "Copy URLs to ClipBoard" for it to remain in the proper format instead of just copying and pasting from the main textarea itself.
